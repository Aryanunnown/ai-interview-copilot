# Frontend

React, Vite, MUI, React Router, and Zustand frontend foundation for AI Interview Copilot.

## Scripts

```sh
npm run dev --workspace @ai-interview-copilot/frontend
npm run build --workspace @ai-interview-copilot/frontend
npm run lint --workspace @ai-interview-copilot/frontend
```

## Scope

This workspace currently contains layout, routing, theme, protected route scaffolding, and empty page placeholders only.
